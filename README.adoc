== Features
* Fully built user authentication system
* Personal dashboard with inbox, board activity, and upcoming tasks
* Websocket-based real-time board collaboration
* Board invitation and role management system
* Public and private board support

== Access

=== Development Site
* Owned by https://github.com/OmyDaGreat/[OmyDaGreat] and completely usable, though a development instance and thus subject to changes and data deletion
** Recommended only to try out the tool
* https://kanman.malefic.xyz

=== Host Your Own
==== Docker
* Use the provided `docker-compose.yml` as a base through GitHub and/or use
the https://hub.docker.com/repository/docker/maleficmarauder/guptarealty[maleficmarauder/kanman] image from Docker Hub
* Much simpler setup, though with a lot less options for configuration

==== Git
* Clone the repo and open in IntelliJ IDEA or Android Studio
* Provides more control than the Docker setup, such as the ability to edit Kobweb site settings
